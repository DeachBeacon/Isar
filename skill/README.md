## 每一项的写作要求

按官方要求，每项必须写明：

1. **适用场景**——什么情况下用得上
2. **使用方法**——够别人照着做
3. **失效条件**——什么时候它不管用（这条最能体现真实经验）
4. **已验证的效果**——必须有真实数据或案例支撑
5. **从哪些失败/观察中总结**——技能包的可信度来源
